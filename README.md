# Personal website 2.0

A minimalist,fully responsive 3-section personal portfolio website built completely from scratch using HTML, CSS, and vanilla JavaScript. 

---

##  Live Demo & Links
* **Live Website:** [View Live Site](https://silly-supernova.github.io/personal-siteuuuu/)
* **Repository:** [GitHub Repository](https://github.com/silly-supernova/personal-siteuuuu)

---

## Features
* **intro Section:** Clean introductory layout featuring a dynamic, time-based JavaScript greeting that updates based on the local time of day.
* **Interests Section:** Highlights personal passions, hobbies, and favorite music and inspirations.
* **Connect Section:** Direct communication and social links.
* **Responsive Design:** Styled cleanly using CSS Flexbox for seamless viewing across mobile and desktop displays.

---

##  Tech Stack
* **Markup:** HTML5 (Semantic Structure)
* **Styling:** CSS3 (Custom Layouts and Flexbox)
* **Interactivity:** Vanilla JavaScript (Dynamic time-based UI elements)
* **Version Control:** Git & GitHub / GitHub Codespaces
* **Hosting:** GitHub Pages
